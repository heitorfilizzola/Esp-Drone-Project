📌 Visão Geral do Projeto

O ESP-Drone (Sky Sense) é uma plataforma integrada de sensoriamento, telemetria IoT e gestão remota para veículos aéreos não tripulados (drones). Desenvolvido sobre os microcontroladores ESP32-S2 / ESP32-S3, o sistema combina medição óptica precisa de altitude com o sensor Unit Mini ToF 90°, infraestrutura de comunicação em tempo real via broker EMQX Enterprise, orquestração centralizada de firmware Over-The-Air (OTA) com Painel Web e um aplicativo móvel avançado com Edge AI Copilot.

Pilares Fundamentais do Sistema

🛸 1. Hardware & Sensoriamento Onboard

Leitura de distância de alta frequência do sensor Time-of-Flight via barramento I2C, fusão com a malha de estabilização do drone e transmissão simultânea via protocolo CRTP (UDP) e MQTT.

🚀 2. Servidor Central de Gestão OTA

Dashboard Web interativo em Node.js/Express capaz de orquestrar atualizações de firmware em lote para toda a frota de microcontroladores via comando MQTT e download streaming HTTP.

⚡ 3. Infraestrutura & Mensageria

Broker EMQX Enterprise para roteamento de baixa latência em TCP (1883) e WebSockets (8083), com regras de persistência SQL conectadas a banco de dados MariaDB.

📱 4. Aplicativo Móvel com IA Copilot

Aplicativo móvel multiplataforma (iOS/Android) desenvolvido em React Native e Expo para acompanhamento de telemetria em tempo real, extremos de voo e detecção preditiva de turbulências.

🚀 Servidor Central de Gerenciamento OTA

Para eliminar a necessidade de atualizações manuais aparelho a aparelho, toda a infraestrutura de firmware agora é orquestrada centralizadamente pelo Servidor Central (server/) via interface Web unificada.

Vantagem Operacional: O operador pode compilar o firmware no PlatformIO e, com um único clique no painel Web, despachar a atualização para múltiplos drones simultaneamente ou para um drone específico na frota.

🖥️ Painel Web Hero

Interface moderna em http://<IP_SERVIDOR>:5000 com botão de destaque "INICIAR ATUALIZAÇÃO DE FIRMWARE (OTA)" e status instantâneo do sistema.

📡 Orquestração via MQTT

O servidor publica a instrução no tópico drone/cmd/ota com a URL do binário (ex: http://172.20.10.2:5000/firmware.bin).

📥 Pull Nativo via HTTPUpdate

O ESP32 recebe o comando, suspende leituras periféricas e baixa os blocos via biblioteca nativa HTTPUpdate, reportando progresso contínuo no tópico drone/ota/status.

⚡ Logs em Tempo Real (SSE)

Transmissão contínua de eventos via Server-Sent Events (SSE) para o navegador, permitindo acompanhar o log de gravação e resposta de cada nó em tempo real.

Fluxo de Atualização Over-The-Air:

[ Operador no Dashboard Web ]
              |
              | 1. Clica em "Iniciar Atualização de Firmware"
              v
[ Servidor Central (Express) ] 
              |
              | 2. Publica JSON no MQTT: drone/cmd/ota { url: "http://.../firmware.bin" }
              v
[ Broker EMQX ] 
              |
              | 3. Encaminha para os microcontroladores inscritos
              v
[ ESP32-S3 / ESP32-S2 ]
              |
              | 4. Conecta via HTTP GET no servidor e grava na partição ota_0/ota_1
              | 5. Publica progresso percentual: drone/ota/status { progress: 85%, status: "flashing" }
              v
[ ESP32 Reinicia Automaticamente no Novo Firmware ]

📱 Aplicativo Mobile & Edge AI Copilot

O DroneTelemetryApp é o aplicativo móvel oficial do projeto, desenvolvido com React Native e Expo (SDK 58). Projetado para operadores em solo, ele se conecta diretamente ao broker EMQX via WebSocket seguro (8083).

📊 Aba Telemetria em Tempo Real

Exibe leituras contínuas do sensor ToF 90° em milímetros (mm) e centímetros (cm), cálculo dinâmico de altitude máxima e mínima de voo (com botão de reset), indicador luminoso de conectividade MQTT e gráfico vetorial interativo (SVG) da variação de altitude.

🧠 Aba IA Copilot & Diagnóstico

Mecanismo de Edge AI embarcado que realiza cálculo de dispersão, desvio padrão e gradientes bruscos de elevação. Emite pontuação de estabilidade de voo (Score %), detecta anomalias de solo/superfície e gera recomendações automáticas de calibração PID.

Configuração Resiliente do App: O aplicativo suporta variáveis de ambiente dinâmicas (EXPO_PUBLIC_MQTT_BROKER_URL, EXPO_PUBLIC_MQTT_TOPIC="drone/#") com sanitização automática para senhas e wildcards que contenham caracteres especiais como #.

📡 Especificação de Mensageria MQTT

A tabela a seguir descreve os tópicos oficiais de mensageria utilizados no ecossistema:

Tópico Origem ➔ Destino Protocolo Função
drone/sensor/tof90 ESP32 ➔ EMQX / DB MQTT (TCP 1883) Publicação de telemetria de altitude em mm/cm e timestamp.
drone/# EMQX ➔ App Mobile WebSocket (8083) Subscrição wildcard consumida pelo aplicativo mobile.
drone/cmd/ota Servidor ➔ ESP32 MQTT (TCP 1883) Ordem de início de atualização com URL do binário de firmware.
drone/ota/status ESP32 ➔ Servidor / Clientes MQTT (TCP 1883) Reporte de progresso em porcentagem (0-100%) e status de flashing.

Payloads de Exemplo

1. Telemetria do Sensor ToF (drone/sensor/tof90):

{
  "device_id": "esp32s3_tof90",
  "sensor": "U196_ToF90",
  "distance_mm": 275,
  "distance_cm": 27.5,
  "valid": true,
  "timestamp": 458920,
  "ip": "172.20.10.3",
  "version": "1.2.0"
}

2. Ordem de Atualização de Firmware (drone/cmd/ota):

{
  "action": "update",
  "url": "http://172.20.10.2:5000/firmware.bin",
  "version": "1.3.0",
  "target": "all"
}

3. Status de Progresso OTA (drone/ota/status):

{
  "device_id": "esp32s3_tof90",
  "status": "downloading",
  "progress": 68,
  "message": "Gravando bloco na Flash (ota_0)"
}
